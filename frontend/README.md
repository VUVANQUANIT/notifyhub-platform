# NotifyHub Frontend

Angular dashboard cho tenant admin và campaign operator.

## Planned modules

- Login và refresh session.
- Tenant/member management.
- Campaign editor và recipient import.
- Message delivery timeline.
- Metrics dashboard.

Khởi tạo sau khi API contract của backend ổn định:

```powershell
npm install -g @angular/cli
ng new notifyhub-web --routing --style=scss
```
